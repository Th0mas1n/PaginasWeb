# PaginasWeb

Este repositorio contiene el código fuente exportado de la página `infosecpro.tech`, un sitio que utiliza la plataforma Shopify. El archivo `codigo fuente de mi pagina.sh` incluye el marcado HTML que hace referencia a hojas de estilo, fuentes y scripts alojados de forma externa.

## Uso

No se requieren dependencias ni pasos de compilación. Para ver el contenido basta con abrir `codigo fuente de mi pagina.sh` en un navegador web con acceso a Internet, pues los recursos se cargan desde los servidores originales.

## Procedencia de recursos externos

- **Shopify**: varias librerías y fuentes se descargan desde dominios como `bn08uu-tn.myshopify.com` y `fonts.shopifycdn.com`.
- **infosecpro.tech**: las hojas de estilo, imágenes y otros elementos estáticos se obtienen del CDN `infosecpro.tech`.

Estos recursos son necesarios para que la página se muestre correctamente.
